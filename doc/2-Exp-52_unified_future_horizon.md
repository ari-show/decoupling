# 2-Exp-52: 統一アーキテクチャの未来日性能を 7 日マスクで確認する

作成日: 2026-10-23
対応ボード項目: 2-Exp-43 で見えた統一モデルの未来日優位（0.05090）の再現確認
関連: [2-Exp-43_future_covariate_masking.md](2-Exp-43_future_covariate_masking.md)、
[2-Exp-42_unified_architecture_ladder.md](2-Exp-42_unified_architecture_ladder.md)、
2-Exp-51（事前スクリーニング、7 日マスク）、2-Exp-48（主表の長い予算での取り直し）

（実験 ID は 45〜51 が使用済みのため 52 を使う。作業場所は `/home/shota/worktrees/exp52`、
ブランチは統一モデルの実装がある `Experiments/2-Exp-43` から分岐。`data/` は symlink 共有。）

## 背景

2-Exp-43（horizon 2 日、6000/1500、120 epoch / patience 8）で、統一アーキテクチャ
`unified_single_decoder` の未来日 MAE は 0.05090 であり、現行モデル 0.05487 を上回っていた。
ただし同実験では窓内 MAE も 0.03192 と他の 0.049 から乖離しており、
評価条件が揃っているかの確認が残っていた。

2-Exp-51 で現行モデルの未来日性能を horizon 7 日・240 epoch で測り直した
（0.05719、改善率 23.6%）ので、統一モデルを**同一条件**で回して比較する。

## 確認したいこと

1. 統一モデルの未来日優位が horizon 7 日・240 epoch でも再現するか。
2. 窓内 MAE の乖離が何に由来するか。
3. 再現する場合、それは「未来日の day 効果を当てている」からか、
   それとも別の理由か。

## 実験条件

2-Exp-51 と同一条件（FreshRetailNet 6000/1500/1500、`series_mean` 残差、dim10、
epochs 240 / patience 24、5 seed = 17/23/31/47/59、`future_mask_days: 7`、
`future_mask_channels: [0, 1]`）で、3 variant を同一 sweep 内に置く。

| variant | 位置づけ |
|---|---|
| `empirical_anova_main_effects` | 学習なしの対照（未来日は `global + hour` の持ち越し） |
| `output_decomp_centered` | 現行の提案手法（2-Exp-51 と同一設定） |
| `unified_single_decoder` | 統一アーキテクチャ（1 バックボーン + 単一 decoder + ANOVA 射影） |

合計 15 run。

## 結果

全 15 run を約 25 分で完走（11:40:30〜12:05:27）。5 seed の平均 ± SD。

| variant | 未来日 MAE | 未来日改善率 | 窓内（可視 21 日）MAE | 窓全体 MAE | 未来日 bias | 未来日 hour corr |
|---|---:|---:|---:|---:|---:|---:|
| empirical ANOVA | 0.06021 ± 0.00000 | 19.6% | 0.05249 | 0.05437 | −0.0091 | **0.9974** |
| `output_decomp_centered` | 0.05719 ± 0.00059 | 23.6% | 0.04624 | 0.04892 | −0.0253 | 0.9947 |
| **`unified_single_decoder`** | **0.05342 ± 0.00018** | **28.7%** | **0.01950** | **0.02779** | −0.0304 | 0.9821 |

未来日 baseline は 0.07488（3 variant 共通）。

### 1. 再現する

2-Exp-43 の horizon 2 日では 0.0719 → 0.05090（**29.2%**）、
本実験の horizon 7 日では 0.07488 → 0.05342（**28.7%**）。
**horizon を 3.5 倍にしても統一モデルの未来日優位はほぼそのまま再現した。**
現行モデルに対する差は −0.00377（5 seed すべてで統一モデルが勝ち、SD は 0.00018 と極めて小さい）。

### 2. 窓内の乖離は「加法制約の有無」で説明できる

`unified_single_decoder` の実装を読むと、予測は

```python
decoded = self.decoder(dec_in).squeeze(-1)   # セル単位の自由な関数
grand = decoded.mean(dim=(1, 2)); row = decoded.mean(dim=2) - grand; col = decoded.mean(dim=1) - grand
interaction_component = decoded - grand - row - col
residual_hat = decoded
```

であり、**4 成分は予測を後から ANOVA 射影で分けたもの**である。
予測そのものは「4 つの軸別スカラーの和」に制約されていない。
現行モデルは各成分が自分の潜在表現から独立に 1 スカラーを出し、その和が予測になるので、
構造的に加法的である。この差が窓内の表現力の差になっている。

成分別の分散寄与（観測セル上、5 seed）で確認すると、差は交互作用成分に集中する。

| 成分 | `output_decomp_centered` | `unified_single_decoder` |
|---|---:|---:|
| global | 0.0073 ± 0.0029 | 0.0258 ± 0.0031 |
| day | 0.0176 ± 0.0117 | 0.0257 ± 0.0010 |
| hour | 0.2893 ± 0.0333 | 0.3359 ± 0.0132 |
| **interaction** | **0.0368 ± 0.0347** | **0.2508 ± 0.0110** |
| fit R² | 0.3687 ± 0.0514 | **0.6306 ± 0.0072** |
| 交互作用の rank-1 比 | 0.683 ± 0.391 | **0.292 ± 0.005** |
| 中心化違反（4 指標） | 0.000 | 0.000 |

**統一モデルの精度優位はほぼすべて交互作用成分から来ている**（0.251 対 0.037）。
その交互作用は rank-1 比 0.29 であり、「系列ごとの 1 つの時間帯形状 × 日ごとの強さ」
という構造では説明できない。つまり統一モデルの交互作用は、
**周辺で説明できない非加法成分をすべて飲み込む catch-all** である。
中心化違反はどちらも 0 だが、これは統一モデルでは射影の定義から自明に成立するものであり、
現行モデルのように head の出力に課した制約ではない。

### 3. 未来日優位は「日効果を当てている」からではない

統一モデルは `cell_mask = mask_grid[..., :1]`（売上チャネルのマスク）で
バックボーン特徴をプールする。未来日はこのマスクが 0 なので、
**z_day は未来日について恒等的にゼロ**になる。共変量も、前日までの系列情報も入らない。
2-Exp-43 の P2（共変量マスクで差が厳密に 0）はこの構造の帰結である。

対して現行モデルの `DayEncoder` はチャネルごとにプールするため、
マスクされていない共変量チャネル（割引・休日・天候）の平均はそのまま通り、
さらに日方向の GRU が前日までの文脈を運ぶ。

したがって、**統一モデルの未来日優位は `global + hour` の持ち越しが上手いことによるもの**で、
未来日の day 効果を当てているわけではない。
現行モデルは未来日に共変量を使えるが、その利得は 2-Exp-43 の P3（共変量マスクで +0.0004、
有意でない）のとおり小さく、持ち越しの質の差に負けている。

### 4. 付随して見つかった不具合: day head の退化

7 日マスク条件の `output_decomp_centered` は、**seed 47 で day 成分が完全に定数に退化した**
（系列内中心化後の標準偏差が 0.000000、他 4 seed は 0.017〜0.023）。
実測の日効果との相関は、生きている 4 seed で 0.728〜0.732 である。
28 日中 7 日を隠すと day head が学習に失敗することがある、という安定性の問題であり、
2-Exp-51 で未来日の day シェアの予測力が消えていた（相関 +0.031）こととも整合する。

## 読み取り

1. **統一モデルの未来日優位は本物で、horizon 7 日でも再現する**（28.7%）。
   未来日性能だけを基準にするなら統一モデルを採る理由がある。
2. **ただし同じ「4 成分の分解」ではない**。統一モデルの分解は自由な予測への後付けの射影であり、
   交互作用成分が非加法項の catch-all になる（分散寄与 0.251、rank-1 比 0.29）。
   現行モデルの「4 つの軸別スカラーの和」という制約は精度を犠牲にして
   成分の意味を固定しており、トレードオフの位置が違う。
3. **したがって本実験は主提案を差し替える根拠にはならない**。
   両者は「加法制約を課すか、後から射影するか」という別の設計であり、
   どちらを主提案にするかは精度ではなく、成分に何を保証したいかで決める。
4. 統一モデルの解釈可能性を現行モデルと同じ土俵で測るには、
   2-Exp-50 の潜在差し替えテストを適用する必要がある。
   現状の `UnifiedDecompositionResidualModel` は `forward` しか持たず
   encode/decode が分離していないため、そのままでは測れない（次の実験）。
5. day head の退化（seed 47）は、未来日マスク条件での学習安定性の課題として記録する。

## 原稿への反映

- 未来日の節に統一モデルの数値を併記する場合は、**加法制約の有無を必ず添える**。
  「統一モデルの方が未来日 MAE が良い（0.0534 対 0.0572）が、
  その差は非加法の交互作用項によるもので、成分の担当範囲の保証は別物である」と書く。
- 2-Exp-43 の統一モデルの数値（0.05090）は horizon 2 日の値であり、
  本実験の 0.05342（horizon 7 日）と直接比較しない。
- 現行モデルの未来日 day 成分については、共変量の寄与が小さいこと（2-Exp-43 P3）と
  seed 47 の退化を limitation に書く。
