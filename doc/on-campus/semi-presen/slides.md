# 中間発表 スライド構成案

更新日: 2026-07-30

**各ページの実際の内容・意図・目安時間は [slidev/slides.md](slidev/slides.md) が正**（意図と時間は各スライドの発表者ノートに記載）。このファイルは構成の決定事項と全体設計だけを持つ。

## 制約条件

- 発表時間 8 分
- 本編は 12 ページを上限の目安とし、1ページ40秒以内
- 発表はパワーポイント（PowerPoint / Keynote）による説明が基本
- タイトルは 4 月頭の主題提出で固定: 「需要予測のための共通要因と系列固有要因の分離表現学習に関する研究」

## 構成方針（2026-07-20 決定）

**演繹型で進める**: 背景 → 先行研究 → 課題 → 提案 → 実験 → 結論。提案・主結果を冒頭で先出しする Top Down 案も検討したが、従来研究から提案へ論理でつなぐ形を採用した。

当初あった「論文原稿の行数比を発表の重み付けに使う」方針は廃止（論文と口頭発表では役割が違う）。代わりに以下を原則とする。

1. **先行研究は 2 枚で扱う** — 1枚目で原論文の方法と実験結果、2枚目で「言えること／言えないこと」と本研究の拡張を明確にする
2. **本文の実験は実験2だけ** — 実験1 Synthetic、数式証明、全条件の corr、bootstrap、補正器の詳細比較は appendix に回す
3. **背景は初心者が観察できる売れ方から始める** — A店×牛乳について「普段は夕方に多い／ある日は一日中多い／ある日の夕方だけ多い」→ 系列の定義 → 平均による基準値 → 基準値からのズレ、の順で進める。発注量や在庫量を直接決める研究とは言わない
4. **タイトルとの整合は表紙の一文で** — 「主題提出時は潜在表現の分離を軸としていたが、実験の結果、分離を出力レベルまで拡張する必要が分かった」と、路線変更ではなくタイトルの問いを遂行した結果として語る
5. **データセット説明の専用ページは作らない** — 背景で「店舗×商品ごとに予測する」とだけ示し、実験2では FreshRetailNet-50K の名称を脚注に置く
6. **従来研究の global を「系列間共通」と呼ばない** — Tonekaboniらの global は各系列内で時間に依存しない特徴、local は時間とともに変化する特徴。原論文が保証・検証した範囲に表現を合わせる

## 2026-07-30 指摘を受けた修正方針

1. **系列は具体的な売れ方を観察した後に定義する** — 最初の背景では専門用語を使わず、「普段は夕方に多い／ある日は一日中多い／ある日の夕方だけ多い」と示し、次のページで「A店×牛乳の売上を日・時間帯順に並べたもの」と説明する
2. **背景の具体例を提案出力へ直結させる** — A店×牛乳、基準値10本という1つの例を通して、系列 $g$・日 $a$・時間帯 $c$・日×時間帯 $u$ の4成分を数値で説明する
3. **雨・イベントと4成分を混同しない** — 雨・イベントはズレの原因候補または入力特徴量であり、提案法が直接分ける出力ではない。本研究が説明するのは「原因名」ではなく「ズレが現れた単位」
4. **潜在変数と出力成分を分けて説明する** — 各 $z$ について、入力、集約する軸、Decoder出力を表で示す。潜在変数は人手で意味を入れた箱ではなく、残差予測誤差から学習される圧縮表現である。実装名 $z_{\mathrm{global}}$ は、系列全体の補正 $g_i$ との対応を明確にするため、発表では $z_{\mathrm{series}}$ と呼ぶ
5. **何が学習されるかを明示する** — 教師信号は4成分の真値ではなく各セルの残差。残差MAEを主損失、潜在間の共分散ペナルティを補助損失としてEncoderと成分別Decoderの重みを同時学習し、中心化制約で出力成分の担当範囲を固定する
