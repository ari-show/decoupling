取得日: 2026-10-23（GitHub CLI、`ShotaArima/decoupling`）。対象は open PR 13件。各 PR の説明、変更ファイル、コミット数、レビュー／コメント、ブランチの base を確認した。各 PR は [GitHub の PR 一覧](https://github.com/ari-show/decoupling/pulls) から参照できる。

## 全体像

中心テーマは、売上時系列を系列全体・日・時間帯・日×時間帯の成分に分けるモデルについて、予測精度と各成分の解釈可能性を確かめること。2026年8月のモデル方向性の検証から、9月の未来共変量の評価問題、10月の成分解釈・学習量・マスキングの検証へと進んでいる。並行して投稿用要旨と考察文も準備中。

大きな学術的な読み取りは次の通り。

1. **中心化出力分解の価値は、精度差だけでなく成分を介入・解釈できる構造にある。** 長い学習では no-center も改善し、centered との精度差は縮む。一方、成分の意味を保つうえでは中心化が重要。
2. **成分解釈の一部は学習量依存。** day と interaction の大小関係、global 成分の定数性は安定した主張にできない。bias が global 成分に局在する所見は残る。
3. **時間帯成分が残差構造の主役。** 2-Exp-44 では残差分散寄与 hour 0.362、day 0.027、interaction 0.021。成分 ablation では day と interaction の寄与は同程度。
4. **評価設計の公平性に未解決点がある。** 未来日評価で過去の設定は天候を見ていた。これを除く追試 #49 は現在の PR 本文上、結果が未追記。
5. **中心化を持つモデルは、介入時の軸間漏れを構造的に抑える。** #56 の全グリッドではほぼ厳密な分離だが、欠品セルを除く評価では漏れが残る。構造保証と実データの部分観測下での性質を区別すべき。

## 論文・研究上の結論候補

- 論文の主軸は「単純に最も高精度」から、「同程度の精度を保ちつつ、成分に意味を割り当て、反事実操作で担当範囲を検証できる」へ置き直すのが、#48・#50・#54–56と整合する。
- 数値の強い主張には学習予算を併記する。特に 60/8 の centered 対 no-center 差だけを代表値として出すと、no-center の学習不足を含む可能性がある。
- 「dayよりinteractionが大きい」「globalは定数」「イベントごとに異なる形」「販促で需要が食い合う」は現状の結果からは主張しない。
- 未来日評価では、#49により天候・販促の先読みを除いても統一モデルの優位が維持された。一方、統一モデルは未来日共変量を使わず、休日・曜日・計画販促を捨てているため、既知共変量を活用した改善余地がある。
- #57の短履歴効果は特定のkeep率・variantで成立し、移植性は強化されない。マスキングを汎用改善としてまとめない。
