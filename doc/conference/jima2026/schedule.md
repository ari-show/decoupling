# JIMA 2026年秋季大会：発表申込・予稿提出

更新日: 2026-08-22（公式資料への参照を追記）

対象: 公益社団法人日本経営工学会（JIMA）2026年秋季大会。2026年10月23日（金）〜25日（日）に姫路で対面開催される。

## 結論

**8月31日（月）は原稿PDFの締切ではなく、発表申込（題目と概要）の締切である。**
予稿PDFは **9月28日（月）** までに提出する。8月31日の締切時刻は公開資料で明示されていないため、余裕をもって完了する。

## 重要日程

| 期限・期間 | 必要なこと | 形式・注意点 |
| --- | --- | --- |
| 〜 2026-08-31 | 発表申込 | 題目と概要400字を登録する。英文概要は公式表記で800ワード。申込者が登壇者となる。 |
| 〜 2026-08-31 | 大会専用Web IDの発行 | 氏名（日・英／ローマ字）、所属、一般／学生、メールアドレス、緊急連絡先、発表種別、パスワードを登録し、メール認証を完了する。 |
| 〜 2026-08-31 | 題目・著者順・所属の確定 | 申込情報からプログラムが作成される。締切後は登壇者名・所属を変更できないため、題目と著者順もこの時点で確定する。 |
| 2026-09-01〜09-28 | 予稿PDFの作成・アップロード | 原則2頁（最大4頁程度）、A4横書き2段組、PDF、3 MB以下。大会配布のWordテンプレートを優先して使う。 |
| 〜 2026-09-28 | 予稿提出の完了 | 締切後は差替・修正できない。未提出の場合、発表は自動的に取り消される。 |
| 〜 2026-10-09 | 参加登録料の事前支払 | 発表者・共著者とも参加登録料が必要で、原則として会場に同席する。 |
| 2026-10-23〜25 | 大会で口頭発表 | 対面開催。通常は1件20分（発表15分、質疑5分）。 |

## 8月31日までに用意する内容

発表申込時に提出する概要は、研究目的・方法・現時点の結果・考察を400字に圧縮したものとする。現時点の研究では、少なくとも次の5点を各一文程度で含める。

1. 小売需要予測において、どの残差構造を問題にするか。
2. 提案する4成分分解の方法。
3. 比較方法と使用データ。
4. 得られた主結果。
5. 実務的・学術的な意義。

申込時点で確定すべき項目は、**題目、著者順、所属、登壇者、400字概要**である。

## 9月28日までに用意する予稿

予稿では目的・方法・結果・考察を明確に記載する。「詳細は当日発表する」として結果や考察を省略しない。レイアウトは大会サイト配布のWordテンプレートと作成要領を優先し、現行要領のA4、上下左右約20 mmの余白、本文10.5 ptを守る。

## 補足

- 非会員でも発表できるが、参加登録と登録料の支払いは必要である。
- 修士学生が Best Presentation Award を希望する場合は、8月31日までに学生会員手続とBPA希望の登録を済ませる。指導教員を共著者に含める必要があり、OS発表は対象外。
