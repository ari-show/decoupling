# Q&A メモ: 全期間成分 $g_i$ はなぜ必要か（「4 つに分ける理由」への回答）

作成日: 2026-10-23
関連: [proposal_direction.md](proposal_direction.md)、[../domestic-2026-checklist.md](../domestic-2026-checklist.md)、
[../../2-Exp-40_jima_main_results.md](../../2-Exp-40_jima_main_results.md)

## 0. 想定質問

> なぜ 4 つに分けるのか。全期間の水準だけなら基準値と同じで、形が出ません。

設計当初も「全期間成分 $g_i$ は基準値に押し込められるので、ほぼ空になるだろう」と
想定していた。実験で確認した結果、**この想定は半分正しく、半分外れていた**。
本メモはその確認結果と、質問への回答方針をまとめる。

## 1. 確認結果の要約

| 論点 | 結果 |
|---|---|
| $g_i$ を抜いたときの MAE 悪化 | **+0.0056**（hour +0.0116 に次ぐ 2 位。day +0.0026、interaction +0.0021 より大きい） |
| $g_i$ の系列間ばらつき | **sd 0.0012〜0.0080**（平均 −0.015〜−0.021）。ほぼ全系列共通の定数に縮退 |
| 経験的 ANOVA（閉形式）での $g_i$ | **ちょうど 0.0**。ablation delta も 0.0000 |
| $g_i$ の正体 | 平均基準値と MAE 最適点（中央値）のズレの補正。**形ではない** |

つまり「空ではないが、系列ごとの情報はほぼ持っていない」。

## 2. なぜ $g_i$ は系列水準を担えないか

基準値は観測セル上の系列平均（`residual.baseline_method = "series_mean"`）なので、
**残差の系列平均は定義上ちょうど 0** になる。したがって $g_i$ は原理的に
「系列ごとの水準」を表現できない。質問の指摘はこの点では完全に正しい。

実際、閉形式の経験的 ANOVA 版は $g_i$ を残差の系列平均として計算するため
（[`EmpiricalAnovaResidualModel`](../../../src/decoupled_ts/residual_models.py)）、
$g_i$ は厳密に 0 で、ablation delta も 0.0000 になる。

## 3. では NN 版の $g_i = -0.016$ は何か

損失が L1（MAE）なので、定数項の最適値は平均ではなく**中央値**である。
FreshRetailNet の残差分布は右に裾が長い。

| 統計量（観測セル、seed 23） | 値 |
|---|---:|
| 残差の平均 | 0.0000（定義上） |
| 残差の中央値 | −0.0274 |
| 残差の 90 パーセンタイル | +0.1064 |
| 残差の 99 パーセンタイル | +0.4314 |
| 系列ごとの残差中央値の平均 | −0.0422（sd 0.0236） |

全体をわずかに下げるほうが MAE 上は得になるため、$g_i$ は全系列ほぼ共通の
$-0.016$ 程度に落ち着く。これは**基準値の置き方（平均）と評価指標（MAE）の不整合を
吸収しているだけ**で、日・時間帯のような「形」を表しているのではない。

参考: $g_i$ と系列平均売上の相関は $-0.67$（低売上系列でやや大きめの補正）だが、
絶対値の差は小さく、系列固有の構造と呼べる水準ではない。

## 4. 回答の骨子: $g_i$ は情報源ではなく識別のアンカー

4 成分分解は

$$r_{i,d,h} = g_i + a_{i,d} + c_{i,h} + u_{i,d,h}$$

に $\sum_d a_{i,d} = \sum_h c_{i,h} = \sum_d u_{i,d,h} = \sum_h u_{i,d,h} = 0$ の
中心化制約を課した二元配置 ANOVA である。水準を吸う項が 1 つ必要であり、
$g_i$ がその役を担う。**形を出すのは $a, c, u$ の 3 つで、$g_i$ は残り 3 つの意味を
確定させるための項**である。

これは中心化を外した対照条件で直接示せる（2-Exp-44、dim10、5 seed）。

| | centered | no_center |
|---|---|---|
| $g$ の符号 | 全 seed で負（−0.015〜−0.021） | seed ごとに +0.065 〜 −0.049 と反転 |
| day 成分の振幅（観測セル sd） | 0.0176〜0.0223 | **0.0001〜0.0005 に潰れる** |
| interaction 成分の振幅 | 0.0152〜0.0208 | 0.0101〜0.0421 に膨張 |
| corrected MAE | **0.04828** | 0.05422 |

中心化がないと水準がどの成分に乗るか決まらず、day が消えて interaction が
肥大するという恣意的な分解になる。ベースライン 0.06966 からの改善幅のうち
約 1/3 が、この中心化＝4 分割の構造そのものに由来する。

## 5. 一貫性の確認

全期間成分の寄与は条件を変えても 2 位で安定している。

| run | 条件 | global | hour | day | interaction |
|---|---|---:|---:|---:|---:|
| 2-Exp-40 | 主結果 dim10 centered | 0.00560 | 0.01159 | 0.00256 | 0.00207 |
| 2-Exp-43 | 未来日・売上マスク | 0.00565 | 0.01126 | 0.00218 | 0.00151 |
| 2-Exp-43 | 未来日・天候マスク | 0.00564 | 0.01084 | 0.00183 | 0.00161 |
| 2-Exp-39 | 未来日 epochs30 | 0.00537 | 0.01024 | 0.00090 | 0.00069 |
| 2-Exp-40 | 経験的 ANOVA | **0.00000** | 0.01081 | −0.00053 | 0.00000 |

実データの主役は一貫して hour である（ablation +0.0116、
hour profile corr 0.994 ± 0.005）。主張の中心はここに置く。

## 6. 予稿・発表での言い回し

- 「全期間成分で形を出す」とは主張しない。形は day / hour / interaction が担う。
- $g_i$ は「基準値の水準ずれを吸収し、残り 3 成分を形に専念させる項」と説明する。
- [../domestic-2026-checklist.md](../domestic-2026-checklist.md) の A-2 で
  $g_i$ を「1 系列の全期間・全時間帯に共通する残差の水準」と言い換える方針にしているが、
  **実測では系列間 sd がほぼ無い**ため、「系列ごとに異なる水準」と読める書き方は
  実験が支持していない。上の言い回しに寄せる。
- 4 分割の正当化は「4 つの情報源がある」ではなく
  「中心化制約つき二元配置分解で補正の重複を排除し、一意な分解を保証する」で行う。

## 7. 再現手順

```bash
uv run python - <<'PY'
import numpy as np
d = "runs/2-Exp-44_component_interpretation_freshretailnet/dim10/seed_23/output_decomp_centered/"
g = np.load(d + "global_component.npy")[:, 0, 0]
res, obs = np.load(d + "residual.npy"), np.load(d + "observed.npy") > 0
print("g_i mean=%.5f sd=%.5f" % (g.mean(), g.std()))
print("residual median=%.4f mean=%.4f p99=%.4f" % (np.median(res[obs]), res[obs].mean(), np.percentile(res[obs], 99)))
PY
```

ablation delta は `runs/2-Exp-40_jima_main_results_freshretailnet/aggregate.csv` の
`component_ablation_without_{global,day,hour,interaction}_mae_delta_mean` を参照する。
